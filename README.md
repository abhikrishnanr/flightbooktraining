# FlightBook Demo

A training/demo flight booking application built with Next.js App Router, React, TanStack Query, Tailwind CSS, and JSON-file-based storage.

## Features
- Landing page and searchable dashboard
- Flight detail page with seat map and booking form
- Mock backend using `app/api/*` routes and local JSON files in `data/`
- Booking persistence with live seat availability updates
- React Query caching, mutations, invalidation, and devtools support

## Scripts
- `pnpm dev`
- `pnpm build`
- `pnpm start`
- `pnpm lint`
